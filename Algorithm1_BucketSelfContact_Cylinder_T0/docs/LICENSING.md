# Publication / licence checklist

The original code is attributed in the conversation to Sarma and may contain
research or third-party contributions. This package does **not** grant a licence.
Before making the GitHub repository public:

1. Confirm that you have permission from every source-code and data rights-holder.
2. Choose an appropriate open-source licence with those owners, add `LICENSE`.
3. Document authors, citation/publications, and any institutional obligations.
4. Check material, mesh and data provenance, including redistribution rights.
5. Identify SuperLU and other dependencies separately; don't bundle their binaries.
6. Publish as experimental/unvalidated until tests pass, especially self-contact and stress.
